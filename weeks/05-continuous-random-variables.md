# Topic 5 — Continuous Random Variables

**Previous:** [Topic 4](04-discrete-random-variables.md) · **Next:** [Topic 6](06-sampling-distributions.md)

## Goals
- Use the normal distribution and standardize with z-scores.
- Apply the uniform and exponential distributions.

## Key concepts
- Continuous random variable; probability = **area under the density curve**; `P(X = x) = 0`.
- **Uniform** on `[c,d]`: `μ=(c+d)/2`, `σ=(d−c)/√12`.
- **Normal** `N(μ,σ²)`: standardize with `z = (x−μ)/σ`, then read the z-table.
- Inverse problems: given a probability, find `x` — read the table backwards.
- **Exponential**: waiting time, `f(x)=(1/θ)e^(−x/θ)`, `μ=σ=θ`. Memoryless.
- **Normal approximation to the binomial**, valid when `np ≥ 5` and `nq ≥ 5`; continuity correction.
- Normal probability plot for checking normality.
