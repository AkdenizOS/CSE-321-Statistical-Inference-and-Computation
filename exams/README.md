## Adding a paper

File it under the academic year it was sat: `exams/<YYYY>-<YYYY>-<type>.pdf`, or a
folder `exams/<YYYY>-<YYYY>-<type>/` when one paper has several pages. Note the
group letter if the paper has one — this course runs multiple versions. A midterm
or final — blank or somebody's graded answers — is study material, so it lives
here where anyone preparing for an exam will look. If it is somebody's answered
paper rather than a blank one, put the writer's surname in the filename
(`final-answered-altungoz.pdf`) to keep the attribution.
